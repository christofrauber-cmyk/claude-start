# Christof Rauber – personal website

A single-page website: home, about, yoga teaching, book, Instagram (@christofsspace) and contact.

Everything lives in `index.html` (HTML, CSS and a tiny bit of JavaScript). No build step.

## View it
- Locally: download `index.html` and double-click it.
- Online: in the GitHub repo go to **Settings → Pages**, pick this branch and `/ (root)`, save. The site appears at `https://<username>.github.io/<repo>/` after a minute.
